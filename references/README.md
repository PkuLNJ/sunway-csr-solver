# 历史参照

这些参照与当前 main 分支分开保存，不是额外的当前优化版本。

- `fixed-csr/host`、`fixed-csr/cpe`：2026-10-16 交付的固定压力 CSR 原始应用源码、配置和依赖哈希。host/cpe 使用各自预编译依赖，不能直接用两份历史耗时解释为严格同算法纯从核收益。
- `native-ldu-sunway`：曙光源码的神威 MPE 移植版本构建脚本、源码归档和运行身份记录。归档不是本仓库重新编译的证明。
- `x86-original`：原始 x86 二进制及服务器源码位置的身份记录，通过 native 移植记录关联；未从曙光服务器重新拉取完整环境。

bai 大写 B 和此次压力分叉诊断程序不在本次保全范围。
